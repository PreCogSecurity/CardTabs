# Contributing

Thanks for considering a contribution to CardTabs.

## Development setup

1. Clone the repository.
2. `npm install`
3. `npm test` — run the test suite.
4. `npm run lint` — run ESLint.

## Making changes

- The authoritative plugin source lives in `js/jquery.cardtabs.js`. The copies in `docs/` are generated by `npm run build:demo` and must stay in sync — CI verifies this on every push.
- Add or update tests in `tests/` for any behavior change.
- Run `npm test` and `npm run lint` before opening a pull request.

## Reporting issues

Please include the jQuery version, the browser (if relevant), and a minimal HTML snippet that reproduces the problem.
